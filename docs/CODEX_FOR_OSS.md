## Form responses

**Repository justification**

> Courbure makes lattice design for 3D printing reproducible. It fills a closed STL with a graded lattice, measures the resulting mesh and exports 3MF, STL and a replayable recipe. It combines Manifold, Three.js and Rapier with synthetic examples and numerical tests. Optional AI proposals pass a strict parameter gate before users can apply them. Courbure is early-stage; independent adoption is unverified.

**API credit use**

> I would use API credits to reproduce bugs from public reports, review patches, and run regression evaluations of the AI proposal gate on public synthetic briefs. I would also use them to automate release checks and draft release notes grounded in test results. Visitor requests through the optional AI adapter use the visitor's own key.

**Anything else we should know?**

> I used Codex to prepare v0.3.0, reproduce a slicer placement failure and add a regression test to the fix. I would use it to triage reports, review geometry and solver changes and maintain reproducible releases. The guided-drop benchmark is numerical.
