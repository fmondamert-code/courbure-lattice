Manufacturing handoff

3MF + STL

Generate a specimen first.

The package includes 3MF, STL, project JSON and slicing instructions.

  1. Select your machine. Import the 3MF and choose a trusted printer and material profile.
  2. Inspect the paths. Check thin struts, layer continuity, first-layer adhesion and removable supports.
  3. Print a coupon. Measure the result before relying on a predicted property.

A closed mesh is a file check. Printability depends on the process. No G-code is generated without a printer profile, and Courbure does not send jobs to a printer. Project exports may contain your imported geometry and material curves.

YOUR GEOMETRY

Import an envelope

Use a closed, outward-oriented STL solid. Courbure fills its volume with the selected lattice and keeps the original envelope in your project file.

Up to 8 MiB and 50,000 input triangles. No upload. Open or inward-facing shells are rejected. The bounded workbench supports up to 60 × 60 × 48 mm.

YOUR MODEL, YOUR CONTROL

Connect an AI

Choose where your text and design parameters are sent. Geometry files and material curves stay local.

Kept in memory for this tab. Sent over HTTPS to this site’s gateway, then to OpenAI. Never saved in a project, browser storage or application logs.

One request per click. Maximum 1,200 output tokens. No automatic retries. API usage is billed to the key you provide.

Start the supplied gateway on your computer and allow this site’s exact origin. Some browsers restrict access from an HTTPS site to localhost.

Ollama and gateway setup

Qwen2.5-0.5B · Apache-2.0 · WebLLM

A compact model that runs on your GPU. Simple, explicit instructions work best. Every proposal is checked before you can apply it.

Requires a supported WebGPU device. Memory use depends on the GPU; the upstream estimate is around 1.06 GB at a larger context. Public model files are cached in site storage. No API key or API billing.
